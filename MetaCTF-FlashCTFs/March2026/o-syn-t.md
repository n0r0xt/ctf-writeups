# O-SYN-T Writeup

## this is my writeup for the O-SYN-T challenge from MetaCTF March 2026 Flash CTF  



An SSH connection is given which connects to the network osynt.lan  



The solution was to use nmap with the -A flag for an aggressive scan, which adds more aggressive OS and service fingerprinting to the scan.  



In the scan results is the flag: MetaCTF{nm4p\_is\_m4pp1ng\_th3\_w4y\_ev3ry\_s1ngl3\_d4y}
